# **Comprehensive Notes on Strings in Java**

---

## **1. Introduction to Strings**

In Java, a `String` is a class that represents a sequence of characters. It is a part of the `java.lang` package and is one of the most commonly used classes in Java. Strings in Java are **immutable**, which means once a `String` object is created, its content cannot be changed.

### **Example:**

```java
String str = "Hello";  // String literal
String str2 = new String("World");  // Using new keyword
```

The `str` in the above code is stored in the string pool, while `str2` creates a new object in the heap.

---

## **2. String Declaration and Initialization**

### **Using Literals:**

This method uses a string constant that is stored in the string pool.

```java
String name = "Java";
```

### **Using new Keyword:**

Creates a new String object in heap memory.

```java
String name = new String("Java");
```

**Note:** Avoid using the `new` keyword unless necessary, to save memory.

---

## **3. Commonly Used String Methods**

Java provides many built-in methods for string manipulation. Below are some commonly used ones:

### **3.1 Length of String**

Returns the number of characters in the string.

```java
String str = "Hello";
int len = str.length();  // Output: 5
```

### **3.2 Concatenation**

Combines two strings into one.

```java
String s1 = "Hello";
String s2 = "World";
String result = s1 + " " + s2;  // Output: Hello World
```

### **3.3 Substring**

Extracts a part of the string.

```java
String str = "Programming";
String sub = str.substring(3, 7);  // Output: gram
```

### **3.4 String Comparison**

Compares two strings for equality.

```java
String a = "Java";
String b = "java";
a.equals(b);             // false
a.equalsIgnoreCase(b);   // true
```

### **3.5 Searching**

Finds the position of characters or substrings.

```java
String str = "Java Programming";
int pos = str.indexOf("Program");  // Output: 5
```

### **3.6 Replace**

Replaces characters in a string.

```java
String str = "Java";
String newStr = str.replace('a', 'o');  // Output: Jovo
```

### **3.7 Case Conversion**

Converts string to uppercase or lowercase.

```java
String str = "Java";
str.toUpperCase();  // Output: JAVA
str.toLowerCase();  // Output: java
```

### **3.8 Trim**

Removes leading and trailing whitespace.

```java
String str = "  Hello  ";
str.trim();  // Output: "Hello"
```

---

## **4. String Formatting**

Allows formatted output using placeholders.

```java
String name = "Alice";
int age = 25;
String formatted = String.format("Name: %s, Age: %d", name, age);
System.out.println(formatted);  // Output: Name: Alice, Age: 25
```

Useful for aligning strings and preparing output.

---

## **5. Mutable Strings: StringBuilder and StringBuffer**

Immutable strings are inefficient for repetitive concatenation. For such use cases, Java provides mutable alternatives:

### **5.1 StringBuilder (Not Thread-Safe)**

* Provides a mutable sequence of characters.
* Recommended for single-threaded applications for better performance.

```java
StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");
System.out.println(sb);  // Output: Hello World
```

### **Common Methods of StringBuilder**

| Method                                    | Description                               |
| ----------------------------------------- | ----------------------------------------- |
| `append(String str)`                      | Adds string to the end                    |
| `insert(int offset, String str)`          | Inserts string at specified index         |
| `replace(int start, int end, String str)` | Replaces characters between start and end |
| `delete(int start, int end)`              | Deletes characters between start and end  |
| `reverse()`                               | Reverses the string                       |
| `toString()`                              | Converts to String                        |
| `length()`                                | Returns length                            |
| `capacity()`                              | Returns current capacity                  |

```java
StringBuilder sb = new StringBuilder("Hello");
sb.insert(1, "Java");      // HJavaello
sb.replace(1, 5, "i");     // Hiello
sb.delete(1, 3);            // Hllo
sb.reverse();              // ollH
```

### **5.2 StringBuffer (Thread-Safe)**

* Similar to StringBuilder but synchronized.
* Use in multi-threaded environments where thread safety is required.

```java
StringBuffer sb = new StringBuffer("Hello");
sb.append(" World");
System.out.println(sb);  // Output: Hello World
```

## **6. Regular Expressions with Strings**

Regular expressions (regex) provide a powerful way to perform pattern matching on strings.

### **Example:**

```java
import java.util.regex.*;

String text = "User123";
Pattern p = Pattern.compile("[a-zA-Z]+\d+");
Matcher m = p.matcher(text);
System.out.println(m.matches());  // Output: true
```

This regex matches any string that starts with letters and ends with digits.

---

## **7. Best Practices**

* Use `StringBuilder` or `StringBuffer` for repeated string modifications.
* Always use `.equals()` or `.equalsIgnoreCase()` for comparing strings.
* Avoid creating unnecessary string objects.
* Prefer `String.format()` for complex string formatting over concatenation.

---

## **8. Conclusion**

Strings are one of the most essential data types in Java. They support a wide range of operations and methods that help in text manipulation. Understanding how strings work, especially their immutability and alternatives like StringBuilder, helps in writing efficient and optimized code.
